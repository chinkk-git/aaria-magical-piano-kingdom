# Aaria's Magical Piano Kingdom — V1

Standalone PWA for one song: **Dalmatian Cradle Song**. Hosted independently from Aaria's Magical Kitchen.

## V1 features
- Interactive piano keyboard and aligned falling notes.
- Listen and Learn modes, pause, restart, navigation, adjustable speed and vertical timeline swipe.
- Offline support through a versioned service worker.
- Android install prompt and iPhone Safari Add to Home Screen guidance.

## Music accuracy
The note transcription remains provisional. The supplied score images are included for reference, but the rendered note events have not been independently checked note-by-note against a complete authoritative score. Piano accompaniment is incomplete. Do not use this as a verified teaching edition.

## Hosting
GitHub Pages serves this repository root over HTTPS. All application, icon, score and script assets are local. No paid services or external APIs are required.

## Device verification
Desktop browser checks do not replace Android or iPhone hardware testing. Confirm touch alignment, swipe, audio timing, home-screen launch and offline playback on the target phones.

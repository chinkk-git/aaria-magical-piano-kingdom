## Integration approach

- Keep the existing clock, note events, audio oscillator, keyboard geometry, speed input handler, zoom action, song-library data model, favorites, recent history, and storage migrations.
- Expose a small `AariaV21Engine` bridge inside the existing playback closure. The UI calls its existing start/pause/sound/measure behavior; it does not create another playback clock.
- Add `loopEnabled` and exact inclusive start/end boundaries to the current measure completion function. Measure spans and timeline labels use the current song's `TOTAL` and `barLength()` data. Song records are not modified.
- Keep existing saved Piano World choice. On a fresh install, set Classic Piano as the default according to the V2.1 owner decision.
- Render the library's existing favorite/recent/search/arrangement records as compact rows. The existing IndexedDB and localStorage behavior remains unchanged.
- Additive files: `v2.1-ui.js`, `v2.1-ui.css`, and five corrected V2 half-wheel SVG states. The service worker shell is versioned `aaria-piano-v2.1.0` and includes these files for offline use.
- No app-storage schema migration, song-data rewrite, OMR model change, external dependency, or paid service is introduced.

## Known test boundary

The new Chromium workflow uses a synthetic 1,000-measure song and checks the UI, range bounds, playback-loop state, saved-song rendering, and seven target viewport sizes in both Piano Worlds. This does not replace physical-device audio/touch testing. The app's existing OMR install gate is bypassed only inside the isolated screenshot test harness; this workflow does not re-test OMR model download or offline recognition.

## Rollback

If owner review finds a V2.1 regression, revert this PR's application changes on a follow-up branch and publish a new monotonically higher service-worker build after approval. Existing song records and caches need no migration rollback: V2.1 adds no stored-song fields and does not delete old cache data during testing. The implementation branch is not merged or deployed by this worker.

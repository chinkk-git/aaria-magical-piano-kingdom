# Phase 1 known limitations

- SVG layers provide visible bevels, raised sidewalls and reflections; there is no native 3D model or WebGL renderer.
- Make Music and the five Navigation glyphs are documented adaptations because the supplied wheel set does not contain those five named actions.
- The focused browser workflow uses Chromium viewport emulation. It does not establish physical Android, iPhone, iPad, MacBook, touch or GPU behavior.
- The test harness renders an isolated fixture song and hides the OMR installation gate in its browser only; OMR installation is not tested by the Magic Star visual suite.
- The fixed playback dock is checked at the specified viewports. No production build or PWA installation/update was performed.
- Owner visual acceptance remains pending. A passing automated run does not approve the artwork or motion.
- If any label, geometry, runtime or interaction assertion fails, the workflow packages the captured diagnostic screenshots and marks the run failed.

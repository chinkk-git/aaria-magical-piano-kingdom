# Phase 1 known limitations

- The responsive matrix uses Chromium viewport emulation; no physical-device verification is claimed.
- Both source archives contain SVG/PNG art, not native 3D model geometry, and the original wheel names four Music actions.
- The fifth Music segment, Make Music icon, Navigation action art and labels are provisional adaptations documented in the asset map.
- The original package has no explicit license or broad redistribution grant. This work is limited to the owner's authorized integration and review.
- Video and opening/closing frames are browser-emulated; they do not prove physical-device GPU performance.
- Secondary panels and unrelated Release 2 features are outside this correction.
- Owner approval is pending. Merge, deployment and release are not performed.

The screenshot harness seeds an isolated local test song and hides the OMR installation gate to render gameplay in the test browser; this does not test OMR installation or alter owner device storage.\n
